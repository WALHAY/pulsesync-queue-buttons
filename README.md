# QueueButtons

Две кнопки очереди рядом с лайком в Яндекс Музыке:

- **Играть следующим** — добавляет трек сразу после текущего.
- **Добавить в конец очереди** — добавляет трек после уже выбранных.

Кнопки появляются при наведении на строку трека или фокусе с клавиатуры. Работают в поиске, альбомах и разделе «Мне нравится». Текущий трек продолжает играть.

В «Моей волне» выбранные треки добавляются перед рекомендациями.

## Установка

Нужны [PulseSync](https://pulsesync.dev) и модифицированный клиент Яндекс Музыки.

Перетащите файл `.pext` в PulseSync и включите QueueButtons. Чтобы собрать файл из исходников, выполните в папке проекта с Node.js 24 или новее:

```sh
npm ci
npm run build
```

Готовый файл: `dist/QueueButtons-1.1.5.pext`.

Если перетаскивание на macOS не сработало:

```sh
open -a PulseSync dist/QueueButtons-1.1.5.pext
```

## Разработка

Исходники находятся в `addon/`. Проверки после `npm ci`:

```sh
npx playwright install chromium --only-shell
npm run check
npm test
```

Тесты используют имитацию клиента. Перед публикацией проверьте аддон в самой Яндекс Музыке.
