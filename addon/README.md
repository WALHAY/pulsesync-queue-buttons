# QueueButtons

Добавляет две кнопки рядом с лайком в Яндекс Музыке:

- **Играть следующим** — добавляет трек сразу после текущего.
- **Добавить в конец очереди** — добавляет трек после уже выбранных.

Кнопки появляются при наведении на трек или фокусе с клавиатуры. Текущая песня продолжает играть.

Работает в поиске, альбомах и разделе «Мне нравится». В «Моей волне» выбранные треки добавляются перед рекомендациями.
