# QueueButtons

Две кнопки рядом с лайком в списке треков Яндекс Музыки:

- **Играть следующим** — добавляет трек сразу после текущего.
- **Добавить в конец очереди** — добавляет трек после уже выбранных.

Наведите курсор на строку трека, чтобы увидеть кнопки. Они также появляются при переходе клавишей Tab. Нажатие не прерывает текущую песню.

Работает в поиске, альбомах и разделе «Мне нравится». В «Моей волне» выбранные треки добавляются перед рекомендациями.

Для установки импортируйте файл `.pext` в PulseSync и включите QueueButtons. Нужен модифицированный клиент Яндекс Музыки.
