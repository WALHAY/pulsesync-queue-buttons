# QueueButtons 1.1.0

PlayNextInline is now QueueButtons. This release adds a second button for the end of the queue and keeps Play next right beside Like.

For the PulseSync publication form:

```text
- Новое название: QueueButtons. Обновление устанавливается поверх PlayNextInline.
- Добавлена кнопка «Добавить в конец очереди»: треки добавляются после уже выбранных песен, в порядке нажатия.
- Кнопка «Играть следующим» остаётся рядом с лайком; новая кнопка расположена слева от неё.
- Обе кнопки используют оригинальные иконки Яндекс Музыки и работают в поиске, альбомах и любимых треках.
- Обновлены README и инструкция по установке.
```

AI was used during development: **Yes**.

Browser tests use a simulated queue. Check both actions in the desktop client before submitting the release.
